# 📊 Sales Performance & Business Analysis (2022–2024)

### An End-to-End Data Analytics Project Using Python

## 📌 Project Overview

This project focuses on analyzing sales data from 2022 to 2024 to understand business performance, identify sales trends, and generate meaningful insights.

Using Python and its data analytics libraries, three yearly Excel datasets were combined, cleaned, explored, and visualized to evaluate revenue, product performance, regional sales, customer segments, sales channels, and salesperson performance.

The project demonstrates a practical end-to-end data analytics workflow, from raw data to business insights.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Compare yearly and monthly revenue trends.
- Identify top-performing products.
- Evaluate regional sales performance.
- Understand online and offline sales contribution.
- Compare Retail and Wholesale customer segments.
- Analyze salesperson performance.
- Generate actionable business recommendations.

## 📂 Dataset Information

The dataset contains sales records from three years: 2022, 2023, and 2024.

| Year | Records |
|---|---:|
| 2022 | 915 |
| 2023 | 906 |
| 2024 | 917 |
| **Total** | **2,738** |

**Dataset Size:** 2,738 Rows × 8 Columns

### Dataset Columns

| Column | Description |
|---|---|
| Date | Date of sales record |
| Product | Product sold |
| Region | Sales region |
| Units_Sold | Number of units sold |
| Revenue | Revenue generated |
| Salesperson | Salesperson name |
| Channel | Online or Offline |
| Customer_Type | Retail or Wholesale |

## 🔍 Project Workflow

1. **Data Loading & Understanding** – Imported and combined three yearly Excel sheets.
2. **Data Inspection & Quality Check** – Examined data structure, data types, missing values, and duplicate records.
3. **Data Cleaning & Preparation** – Converted the Date column into datetime format and prepared the dataset for analysis.
4. **Exploratory Data Analysis (EDA)** – Answered 15 business questions using Pandas and NumPy.
5. **Data Visualization** – Created 8 charts using Matplotlib and Seaborn.
6. **Business Insights & Recommendations** – Identified important trends and suggested business improvements.

## 📈 Key Business Questions

The analysis answers 15 important business questions, including:

- What is the overall sales performance?
